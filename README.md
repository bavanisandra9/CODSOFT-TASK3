​Project Overview:

​The project is a Simple Calculator Web Application developed using HTML, CSS, and JavaScript, designed to provide a user-friendly interface for basic arithmetic calculations.

​Features:
​Perform basic arithmetic operations (+, -, ×, ÷).

​Clear display functionality (C button).

​Delete last entered character (⌫ button).

​Decimal number support.

​Double zero (00) input option.

​Error handling for invalid expressions.

​Interactive button hover effects.

​Modern and responsive calculator design.

​Technologies Used:

​HTML5: Structure of the calculator.

​CSS3: Styling and layout design.

​JavaScript: Calculator functionality and operations.

​CSS Grid: Button arrangement and layout.

​Sections Included:

​1. Calculator Container: Main calculator body with rounded corners and shadow effects.

​2. Display Screen: Shows entered numbers, operators, calculation results, and features a read-only input field.

​3. Button Panel: Includes number buttons (0–9, 00, decimal point), operator buttons (+, -, *, /), and function buttons (Clear, Backspace, Equals).

​4. JavaScript Functions:

​appendValue(): Adds values to display.

​clearDisplay(): Clears the display.

​deleteLast(): Removes the last character.

​calculate(): Evaluates the expression and displays the result.
